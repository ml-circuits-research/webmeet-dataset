# File names

Files are named by the kind of data they hold: `<theme>-NN.csv` (a number keeps names unique). The theme is the
one most rows share, by the keys of their circuits: in Drawing `people`, `placement`, `objects`, `style`, `edits`, and
`scenes` for files that mix them; in Diagram `charts`, `nodes`, `layout`, and `diagrams` for mixed files; `text` in
Document; `meetings` in Calendar. The table below maps the former names (by origin) to the new ones. A file still
marked *pending* is being repaired; it takes its new name when its repair is committed.
